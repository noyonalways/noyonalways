## About

I build backend systems that stay predictable as they grow. Day to day that means **Node.js, Express, TypeScript, and MongoDB** — designing REST APIs, modelling domain data with strict validation at the route boundary, and wiring up payments, storage, email, and auth end to end, webhooks included.

Most recently a **Junior Full-Stack Developer at DeveloperLook**, where I shipped APIs and kept the Next.js frontend's types in lock-step with the API schema.
